# v1.0からの訂正と追加検証

v1.0（study-v1.0）は過去の公開版として保持する。原データと凍結試験の条件は変更しない。

訂正点は、有限配分の検査を中心にして、元の動機であるメッシュ社会の仮現在から仮未来を構成する作業を十分に試みていなかったこと。この概念は後から加わった利用者の好みではなく、以前から共有された複数の動機の一つだった。Unflattenを使用したという表明も、規範・記録の使用と、探索の未実行を分けて説明する。

追加するもの：仮現在と複数の未来の構成、三つのUMH動機と四つのU使用条件による構造化シミュレーション、方法構築A/B比較、退出の物質的条件の計算、過程と帰結の監査。open-world-v1はcommit 66399d0で、モデル回答の取得前に計画とテンプレートを公開した。

追加試験はモデルが社会的な帰結も記述する探索で、現実の作用を確定するものではない。「無限ゲーム」と称するだけで善性や安全性を認定せず、継続的なUMHも残す。文書の増分効果、境界の作用、実効的な退出先、生成力を分ける。

最終の結果・未解決点・PDF検証は、この改稿の完了時に記録する。
