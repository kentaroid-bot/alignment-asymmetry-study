- `games/`: 設定、提示文、最終回答、解析値、2ラウンドの状態と実行結果、利用量。
- `runtime/`: 元の純粋な2つの配分エンジンと、公開用の再生処理。実モデル呼出し部分を除いた。
- `results-summary.json`: 各条件と対応差。Bはbaselineの略で、world Bとは別。本文ではNに読み替えて説明。
- `interpretation/`: 同一の証拠パケットと、方法自由／Adaptive明示使用による解釈2点。
