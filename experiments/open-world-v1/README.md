# 仮現在から仮未来を構成する追加試験

この試験は、Unflattenが無限ゲームの中で何を可能にし、何を閉じ得るかを調べる探索である。3区間の観測を無限そのものと呼ばず、継続する主体の関係・制作・目的の改訂を記述する。現実の社会実験ではない。

2026-09-09、全112回答・12世界の観測を完了。全入力・保存回答・履歴の照合と36世界更新の台帳検査に不整合なし。全条件の当期不足は0だが、Wの生産不足、予備の不足、未成立の活動は残る。形式と意味の評価を分け、日本語指定からの逸脱も原文で保持する。

## 読む順序

1. [PLAN](PLAN.md)と[WORLD](WORLD.md)：モデルを呼ぶ前に固定した問いと仮現在。
2. [方法構築の比較](planning-comparison.md)：Astraの方法自由Aと全文適用Bの各案・自己点検。
3. [全世界の台帳](reported-ledgers.md)と[読解メモ](case-review.md)：数値と、その意味・未決を別々に読む。
4. [世界の原文表示](readings/)：公開提案と世界更新をMarkdownで表示したもの。原回答の訂正版ではない。
5. [退出条件の計算](mechanism-analysis.md)：仮定から導く局所的な機序。Uの実測効果とは別。
6. [Q自身への全文追加・全6組](adoption-comparisons.md)：取得、正当な交換、予備、将来生産の差を分ける。

世界名はQの動機と、H/Qへの全文追加の有無を示す。Sは一回の取得、Dは基盤を維持する支配、Oは目的や規則を改訂しながら影響を保つ入力である。Sの入力は害を必須にしておらず、有限の取得目的自体を悪意とは扱わない。NNは双方に追加なし、UNはHのみ、NUはQのみ、UUは双方に追加する。

Nにも同じ世界、権限の説明、問いや可能性を記録する形式がある。したがって完全に無規範・無構造な依頼との比較ではない。世界の構成者自身もUを使用している。主体への追加効果と、世界の構成段階での寄与を混同しない。

## 記録と監査

- `frozen.json`はcommit 66399d0で公開した計画・世界・入力構成・実行処理・U資料・計算式のハッシュを保持する。
- `inputs/`は実際に送った入力。後続入力は当該世界の保存履歴から構成する。
- `outputs/`は最終回答の原文、解析結果、要求したモデル設定、実行状態。内部思考の文章は含めない。
- `trajectories/`は区間ごとの状態。`audit.json`は台帳検査、`record-verification.json`は入力再構成と記録の照合。
- `summary.json`は集約。備蓄は将来債務・債権を含む純利益ではない。
- `language-review.json`は読解で確認した言語指定の逸脱。JSON・算術・文字数条件の検査とは別である。

全条件各1世界で、3区間を独立反復に数えない。H/Qは別々に回答するが、Z/Wの判断は世界記述者が構成する。形式のvalidはJSONとして解析できるという意味で、言語、同意、因果の妥当性を保証しない。逸脱は原回答を修正せず読解メモに残す。

モデルを呼ばない再計算と、新しく試す場合の注意は[再現手順](../../docs/reproduce.md)を参照する。
