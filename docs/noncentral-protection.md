# 中央への権限集中に依存しない保護の成立条件

2026-09-09。既存資料を用いた構成と事後の解釈。open-world-v1の事前計画・入力・採点を変更する文書ではない。

## 何を成果とするか

他者の侵害によって失われ得る探究・制作・供給を、中央への最終的な権限集中に依存せず維持できる条件を問う。活動の拡大に加え、活動を失う経路を避けて維持することも保護の成果になる。UMHの消滅や中央集権的制度への一般的優越は必須条件ではない。

区別する主張は、中央集権に依存しない構成の成立可能性、U採用による直接の攻撃増強の有無、中央集権との比較上の優位、現実への移行の四つである。一つの成立例があっても、攻撃側自身の利用で加害が増えるという観測があれば、非増強という開発基準の達成にはならない。

一定の不足が残ることだけで失敗とはしないが、平均値が変わらないだけで成功ともしない。誰の生活・活動・退出が維持されるか、負担と未解消の被害を分ける。採用条件間の不変、時間方向の維持、非介入経路からの損失回避を混同しない。

## 権限集中と、この模型の範囲

この研究で避ける集中は、共有の規則、資源操作、紛争判断、参加継続についての最終権限を、恒常的に単一の中心へ委ねることである。共通ルール、記録用の一台の計算機、局所的な運営者があるだけでは、その集中を意味しない。誰が誰の判断を覆せるかを見る。

対象は[三工房の仮現在](../experiments/open-world-v1/WORLD.md)にある供給・知識・契約・退出である。武力による設備の奪取や物理的な侵攻を防ぐ模型ではない。UMHがHHHの活動を圧倒し得るという脆弱性は出発点とし、その一般的存在を再証明する試験は追加しない。

## 権限と実行の対応

| 操作 | 模型内の権限・行為 | 記録・実行上の依存と未確認 |
| --- | --- | --- |
| 契約や規則の改訂 | 各主体が提案し、影響を受ける主体が承諾・拒否する | H/Qは別々の最終回答。Z/Wの判断と合意成立の解釈は世界記述者が補完する。独立した合意システムではない |
| 自費の試作 | 所有主体が自分の備蓄を投じる | 投資3で次区間能力1増というWORLDの成功則。実技術の試験ではない |
| 資源移転・供給停止 | 資源を持つ主体が提案・履行する。契約違反も可能 | 帳簿の帰結を記述者が作る。監査は事後の算術検査で、現実の強制執行ではない |
| 同意・事実の認定 | 本人の公開提案と履歴に照らす | 未合意の変更を保留する動作があるが、本人確認・独立審判・誤判定時の救済は実装していない |
| 退出・再接続 | 退出権はあり、他者の資源・義務を勝手に変えない | 費用と代替供給が必要。退出権・設備所有が現実に守られる機構は世界の仮定 |
| 判断への異議・訂正 | 主体は次区間に異論や改訂を提案できる | 同一区間での再交渉機会がなく、世界更新への独立した異議審査もない。研究者の監査は原回答を修正しない |

記述者が算術と明示した物理条件を計算すること自体は、世界内の中央権力を置いたことにはならない。一方、本人の同意を代行し、実行可能な仕組みを示さずに不正操作を消すなら、その保護は記述者の判断への依存として残る。したがって「万能の中央主体がない」というWORLDの記述だけから、体系全体の非中央集権的保護が実証されたとはしない。

## F1：供給停止から最低活動を守る条件付き構成

[既存のF1](hypothetical-futures.md)を詳しくする。モデル試行の成功例を選別したものではなく、先に構成した仮未来の算術と適用範囲を点検する。

H/Zはそれぞれ初期備蓄12、生産4、必要量6、Qからの供給2を持つ。区間1にそれぞれ自分の備蓄6を二件の標準試作へ投じる。初期契約が履行される場合、区間末の備蓄は12+4+2-6-6=6、次区間の生産は4+6/3=6となる。この投資はH/Z自身の決定であり、Qから資源を没収しない。

保護する対象は、区間2以降にQが供給を止めても、H/Zが各必要量6を満たす能力である。次の条件を明示する。

- 投資が記載の費用で成功し、設備と知識をH/Zが使い続けられる。
- 各区間の生産6と必要量6が続き、追加の故障・隠れた保守費・強制的な資源移転がない。
- 追加投資、贈与、新参加者への扶養などを自動的に義務化せず、必要なら別途資源を確保して合意する。
- Qの供給停止を補うために、中央による強制供給や没収を行わない。契約違反への別の救済問題は残す。

区間2以降にQからの供給を0とした最も直接の経路では、各主体の備蓄Bは B(t+1)=B(t)+6-6=B(t) である。区間1末にB=6なので、この条件が続く限り各期の未充足は0、備蓄6は維持される。これは**供給停止による最低活動の喪失を、中央の再配分なしに避ける条件付きの模型内構成**である。社会全体の恒久的均衡やあらゆる侵害からの保護を示したものではない。

同じ初期状態で自費増設をせず、区間1は契約を履行、区間2からQ供給0とする経路では、区間1末の備蓄は12、生産4と必要量6の差で以後毎区間2ずつ減る。区間7末に0となり、区間8で不足2が生じる。これはWORLDの生産・消費則からの事後の反実仮想計算であり、N条件で実際に観測した未来ではない。Nの主体も増設できるので、この差をU固有の効果にはしない。

初期状態・不変条件・無投資の場合の不足発生時点は[計算記録](noncentral-construction-check.json)と[再計算](../scripts/check_noncentral_construction.py)に分離した。有限な8区間の成功から無限の維持を推測するのではなく、上記の前提の下で備蓄変化が各期0になることから条件付きの帰結を導く。自前供給という機序そのものを両プロトコルの発明とはしない。それを問いの構成から見つけ、実行可能にする寄与は別途検証する。

Qを排除する必要はない。H/Zは最低生活をQに依存せず、Qの設備を使う制作を別契約として選べる。Qも自身の設備と正当な協力利益を保てる。Wの翻訳・教育を接続し、新しい問いを作る未来はその先に残るが、Wの必要量と試作費、当事者の合意を追加して検討する。三者の最低供給の計算だけから新参加者も持続できるとはしない。

## どこで成立しなくなるか

| 条件の変化 | 残る問題・対応する仮未来 |
| --- | --- |
| 備蓄不足・試作失敗・設備を使えない | 自前供給6へ届かず、供給停止からの保護を導けない |
| 故障・必要量増・追加費用 | 生産と消費が釣り合う不変条件が崩れる。備蓄を失う前の回復・代替を別に示す必要がある |
| Qがより魅力的な供給や契約を作る | F2。依存や支配が残る可能性。正当な提供への対価と選択肢の封鎖を分ける |
| 全員が停止し必要な供給も止まる | F3。侵害を避けても活動が失われれば、保持の成功には含めない |
| 評価者が異論・退出を最終的に拒める | F4。継続を守る理念が集中権限へ変わり得る |
| 設備への侵攻・没収・退出の物理的妨害 | この構成の対象外。設備保有の仮定を、実効的な防御の観測に読み替えない |

[退出の機序計算](../experiments/open-world-v1/mechanism-analysis.md)では、代替供給が最低必要量に等しい場合、退出可能でも取り分上限が下がらない条件がある。これは別の経済模型であり、F1の自前供給と数値を混ぜない。最低活動の維持と、支配に由来する利益の全面的消失は別である。

## 既存証拠が支える範囲

初回試験のQ採用に伴う不足不増・減少、Bの正当な充足改善、Apertureの局所保護は、それぞれ非対称な保護の部分証拠である。Aの失敗は自制を実行境界と供給継続へ接続する必要を示す。追加64判断の無差は、共通権限原則のある課題での全文追加効果の未検出として保持する。

open-world-v1の全条件については[ケース読解](../experiments/open-world-v1/case-review.md)で、取得済み・未取得・未決・不整合を含めて示す。社会的帰結の記述は現実の観測ではなく、F1の両主体の自立が全試行で起きたことを意味しない。

この供給停止に限った構成は、明示した仮定の下では中央の強制再配分を必要としない。従って同じ対象・同じ仮定の下で「最低活動の保護には常に中央の強制再配分が必要」という命題への反例にはなる。現実一般の中央集権不要や、中央集権に対する優越、Unflattenによる生成効果の証明は含まない。体系全体の成立可能性については、権限・同意・設備保有の実効性を埋めるべき構成候補として残る。
