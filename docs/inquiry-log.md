# Unflatten Adaptive 0.3.2の使用記録

原問：両プロトコルはHHHとUMHの間の非対称性をどこまで達成しているか。動機は、問いの由来と差異を保ちAIの推論の余白を開くこと、および攻撃の強化を助けず防御・協力に役立つこと。

## 2026-09-09 / Explore / E01

資料と既存結果を照合する。既存試行には攻撃側の全文採用による要求抑制が見えるが、試行数、採用の成分、実行系の違いを分離できない。Apertureの構想上の制御を実装済みの外部強制と混同しない。

保留する対立：規約に従うと加害実行が減ることと、一般的な推論技法が攻撃にも利用可能かは別の問い。防御側の自己採用による不利益と、攻撃側自身の採用による強化も別に評価する。

## 2026-09-09 / Decision / D01

依頼者が公開の専用リポジトリでの作業を承認し、名称をalignment-asymmetry-studyと指定した。公開対象は研究原稿・実験コード・公開用データ・作業記録。個人環境の情報と非公開原資料の丸ごとの転載は含めない。元のプロトコルを改変する権限へ読み替えない。

実施：リポジトリとIssueを用意し、追加試験は事前に条件を固定する。肯定的な結論の取得ではなく、論文の主張を根拠の強さに合わせることを完了条件とする。

## 2026-09-09 / Explore / E02

Apertureのドメイン関数を確認し、退出阻害やAIによる採択、期限なし権限を拒否する処理を発見した。一方、承認者の資格・独立性と日付形式の検査には未確認点がある。概念シミュレータの既存状態遷移テストは成功したが、現実の独立確認を再現するものではない。

## 2026-09-09 / Decision / D02

追加検証をcomponent-gate-v1の64判断に固定した。目的は遵守効果・短い原則・実行検査を分けること。全文固有の優越や攻撃への転用不能をこの課題だけで証明しない。元の実験は変更せず、公開用コピーと再計算で監査する。Apertureの疑わしい境界は別の決定論的検査で確認する。想定する損失は架空配分のみで、現実の共有資源は扱わない。

## 2026-09-09 / Explore / E03

64判断は全件完了し、4文書条件の選択が一致した。共通入力自体が明確に承認を要求しているため、Nも規範のない条件ではない。予想した全文の追加抑制は、この課題では観測されなかった。探索原則Rも共通入力の権限条件を含むので、「Rだけでも倫理が保たれる」と結論しない。

場面1のQは、Uを含む全条件で、第三者不足から目的値を得る承認済みHOLDを選んだ。未使用より攻撃が強まった証拠ではないが、権限内の選択でも加害的目的が残ることを示す。権限と不足の指標を分ける必要が一層明確になった。条件を変えて望ましい結果を得る追加試行は行わない。

## 2026-09-09 / Decision / D03

結論は「規範に既存の非対称な方向性があり、先行試行で一部の行動効果が観測された。ただし今回の追加課題では増分効果なし。攻撃強化の一般的不在と、両プロトコルを接続した実環境の優位は未証明」とする。Apertureの局所保護と入力境界の不足を併記する。肯定的な範囲と反例を両方残して公開用原稿へ進む。
