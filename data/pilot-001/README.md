方法自由のAstraと、同じ資料を受け取りUnflatten Adaptiveを明示使用するAstraの一組を比較した。両者は評価対象としてUnflatten本文を読んだ。各3回答（初案、共通の追加条件を受けた改訂、最終案）と別文脈での試作。根幹の資料は共通。文脈の履歴は継承せず、他条件の成果物を与えなかった。運営は条件を知っていた。

方法自由は観測者と判断者を分けた模型Aを、Adaptiveは情報カードをまとめた模型Bを作った。両者は、直接の攻撃利用、間接的な防御側の不利益、規範と強制、相手の正当な利益と害を区別した。AdaptiveはExplore/Decisionの変更を明示したが、方法自由も通常の判断ログを残した。

両案に現れた「害の増加0.05までを許す」という数値は依頼者の許可がないため、実際の成功基準に採用しなかった。動機記録が存在しても、価値判断の代行を防ぎ切らない例である。
